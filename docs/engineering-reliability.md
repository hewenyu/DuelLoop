# 持续运行工程化修复

本轮基于 `277e2da`，目标是让开发者能够安装 DuelLoop、接入自己的真实环境、配置模型和策略，并可靠地运行和维护双循环应用。Jev 负责全部行动决策，pi 研究必须产出能改变后续行为的策略；模型失败仍停止，不增加程序代打或置信度门槛。

## 发布与研究分开调度

研究通过最终验证后持久化候选发布即完成。发布调度在快循环安全边界独立处理：边界未到、暂停、要求显式批准属于延期；基线改变、验证撤销、依赖失配属于失效；存储等运行故障向调用者抛出。延期不能杀死研究 Worker，也不能重新消费同一批反馈。

研究触发使用 SQLite journal 的单调事件游标和最新反馈修订索引。游标与已触发任务持久绑定，不能以宿主时间戳或有限快照充当消费水位。研究快照是显式有限证据窗口，默认最多 1000 条决策和 1000 条反馈；当前反馈窗口按 journal 提交顺序选择，历史 cutoff 按接收时间回溯；记录具体修订、截断标记和时间边界，后续反馈不会改变旧快照。窗口之外的记录不会自动全部送入下一轮研究。

## 发布使用资格

`assertUsableRelease(releaseDigest, { dependencies, executionMode })` 是运行时检查统一入口：决策、执行准备、激活与回退均检查。研究发布在 live 下必须具有真实模型的有效最终验证；恢复已有数据库不能绕过。bootstrap 是宿主明确选定的初始化发布，不能包装成“研究验证通过”。

模型绑定包括 `modelKind` 和 `modelBehaviorDigest`。每个 `DecisionModel` 声明 `behaviorIdentity`：适配器版本、部署版本、协议版本，以及不含凭据的行为配置摘要。内置 Jev 自动绑定端点、超时及 transport；自定义模型/包装器须主动版本化自己的行为。模型名称相同不表示行为相同。

策略 Schema 保持 `2.0`；评价协议升级到 `3.0`；运行时升级到 `duelloop-runtime-4`；SQLite 从 Schema 1 原子迁移到 2。历史发布和报告不获得新运行资格，保留集额度及原始证据不重置。升级前备份，重新绑定和验证受影响的发布。

## 生命周期

直接 `decide()`、执行准备、框架执行、反馈和核对等异步操作都纳入生命周期；底层模型/领域请求也被跟踪。停止发出取消信号；排空等待真实 Promise 结束，完成停止记录、迟到用量和未知回执写入后才允许关闭。

不能取消的远端动作仍需核对。自定义适配器若忽略取消且永不返回，排空会超时报错，`close()` 不宣告完成，宿主必须保留 store 并处理未完成请求。不能以关闭 SQLite 掩盖在途操作。

## 研究资源

付费研究之前检查最终评价资源，耗尽时进入 `waiting_protocol`，Worker 不领取反馈、不启动模型。最终阶段仍原子领取额度，防止并发研究使用同一份资源。

最终协议注册到持久存储；已有保留集的协议与上限不可修改；同领域的保留集种子不能通过更名再次使用。自定义评价器还必须保证其种子对应真正独立的数据和对手状态，框架不能从一个新 ID 推断数据已经独立。应用显式提供新的独立协议后，后续研究恢复；既有任务的实验标准不会被事后替换。

## 性能口径与验收

`EvaluationProtocol.maxP95DecisionComputeMs` 和报告 `p95DecisionComputeMs` 衡量模拟器的问题构造、模型请求与评分组合；不包含 SDK 观察、存储、执行意图和回执。旧的含糊字段不再接受。

运行时的 `runtime.step_completed` / `runtime.step_failed` 事件分别记录模型时延、从 `step()` 开始到决策落库的时延、执行与回执时延、完整步骤时延及截止时间是否超出。性能实验还在调用者外层计时，以包含遥测本身的落库开销。

`scripts/history-benchmark.mjs` 在 1000、10000、100000 条合成历史上测完整 SDK：每条历史有模型决策、已完成意图、反馈及最新修订索引；分别运行快循环，以及与同库的快照和开发评估并发。记录 P50/P95/P99、超时/停止率、内存、SQLite 写锁获取耗时和快照大小。写锁计时包括 `BEGIN IMMEDIATE` 的执行开销，并非纯粹的阻塞时间。

同步 SQLite 锁等待和同步领域代码仍会占用当前事件循环。时限是异步调用的截止控制，不是对同步代码的硬实时抢占。快慢 worker 隔离可避免同一事件循环争用，仍需测量同库争用。

这轮工程验收使用明确的离线模型夹具，不调用收费模型。真实 Jev Choice、固定 Score、单模型慢循环和团队慢循环的收益、停止率与完整成本消融实验另行执行；工程验收不能证明策略增益。
